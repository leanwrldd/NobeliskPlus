# Nobelisk Plus

A [Satisfactory](https://www.satisfactorygame.com/) mod that makes the Pulse Nobelisk's
shockwave bigger and stronger — larger radius, harder push — without increasing its
damage, and adds a Pulse Rebar with its own tweakable shockwave.

Built with [SML](https://ficsit.app/mod/SML) (Satisfactory Mod Loader).

## Features

- Bigger, stronger Pulse Nobelisk shockwave (radius and push only — damage unchanged)
- New Pulse Rebar ammo with its own shockwave, unlocked via its own research/schematic
- All multipliers are configurable in-game and apply live, no restart needed

## Configuration

Available from the mod settings menu, per weapon (Pulse Nobelisk / Pulse Rebar):

| Setting | Description | Default |
| --- | --- | --- |
| Shockwave Radius Multiplier | How much bigger the shockwave radius is | 2.0x |
| Shockwave Impulse Multiplier | How much stronger the one-shot push is | 2.0x |
| Shockwave Force Multiplier | How much stronger the continuous push is | 2.0x |

## Installation

Install via the [Satisfactory Mod Manager](https://ficsit.app/) or download from
[ficsit.app](https://ficsit.app/).

## Building from source

1. Clone into `<SML>/Mods/GameFeatures/NobeliskPlus` (or symlink/junction it there).
2. Generate project files and build the `FactoryEditor` target as you would for SML.
3. Package with Alpakit.
